- Launch a Linux ec2 instance.
- Create an additional volume in the same region and Availability zone using AWS console where your ec2 instance is launched.
- Attach it to the ec2 instance.
- SSH into your ec2 instance
- type "lsblk" command to see the volumes and mount point
- type "sudo mkfs -t xfs /dev/nvme1n1" to create filesystem
- type "sudo mkdir -p /data" to create mount directory
- type "sudo mount /dev/nvme1n1 /data" to mount the filesystem
- type "df -hT /data" to verify the mount

To make EBS filesystem persistent you have to configure /etc/fstab using the filesystem UUID.

- type "sudo blkid" to identify the filesystem UUID
- or you can type "sudo blkid /dev/nvme0n1" to find specific volume's filesystem UUID
- copy the filesystem UUID
- type "sudo vi /etc/fstab" to open editor 
- paste this line "UUID=YOUR-FILESYSTEM-UUID /data xfs defaults,nofail 0 2" and exit the vi using esc with :wq 
	- UUID=--your UUID--
	- /data : directory where it will be mounted
	- sfs : filesystem type
	- defaults,nofail: Standard mount options; allow boot to continue if the volume is unavailable
	- 0 : Disable the legacy dump backup flag
	- 2 : Filesystem-check order; actual behavior depends on filesystem type and system configuration

- type "sudo findmnt --verify --verbose" to test the configuration
